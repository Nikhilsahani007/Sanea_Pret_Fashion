# Fonts

`archivo-latin.woff2` and `archivo-latin-ext.woff2` are the Latin and Latin
Extended subsets of Archivo (variable, weight 100–900, width 62–125 %),
downloaded unmodified from Google Fonts (`fonts.gstatic.com/s/archivo/v25/`)
on 2026-10-24. Licence: SIL Open Font License 1.1, `OFL.txt`
(from `github.com/google/fonts/ofl/archivo`). Copyright 2020 The Archivo
Project Authors.

They stand in for Panchang and Switzer (design-system.md §4), whose Fontshare
files could not be downloaded from the build environment (D-082). Replace the
files and the `--sp-face` token in `brand.css` to switch faces.
